# Скачать готовую прошивку T23N и записать на SD

Это инструкция для **полного дискового образа** профиля `t23n_sd`, полученного через YadroKreator. Для других плат и процессоров инструкции записи отличаются.

## 1. Дождаться успешного результата и проверить файл

После завершения сборки в разделе **Артефакты** сразу доступна кнопка **«Скачать образ .img»**. Нажатие **не компилирует ядро заново**: перед передачей файла сервер автоматически проверяет SHA-256, MBR, T23N MSPL **LBA34**, BOOT FAT16 `/uImage` **LBA2048** и ext4 ROOTFS **LBA34816**. Если файл повреждён, скачивание блокируется с ошибкой; потребуется новый одноразовый код. Кнопка **«Проверить образ перед записью SD»** в разделе Сборки остаётся для предварительной проверки и карты разделов, но не обязательна для начала скачивания.

При ошибке или отсутствии SHA нужно сначала исправить сборку. Зелёная проверка означает проверку **файла**, а не физической загрузки камеры.

## 2. Получить одноразовый код на Huananzhi

Этот SD-образ может содержать Wi-Fi PSK. Веб-панель **без логина и пароля**, поэтому прямое скачивание по публичному адресу отключено. В доверенном SSH-сеансе Huananzhi:

```bash
cd /1tbdisk/PegineLab/projects/YadroKreator
python3 download_access.py issue ПОЛНЫЙ_ID_ЗАДАНИЯ
```

Полный идентификатор можно скопировать с карточки образа в **Артефакты**. Терминал покажет случайный код, действующий **10 минут и ровно для одного скачивания**. Код не попадает в URL, историю Git или журналы. Создание нового кода заменяет прежний.

Открой в браузере раздел «Артефакты», нажми **«Скачать образ .img»**, вставь код. Получишь файл `WIFICAM_T23N_<id>.img`. Это **точная копия байтов** образа `thingino-t23-sd.bin`, расширение изменено только для удобства программ Windows. Скачивание не изменяет исходный файл на сервере.

**Сетевая безопасность:** по адресу `http://192.168.0.100:62404` нет TLS; в недоверенной сети токен и файл могут быть перехвачены. Используй только доверенную изолированную LAN или VPN с защищённым транспортом. Не открывай TCP 62404 в WAN. Безопасная альтернатива — SCP/SFTP по SSH с серверного пути к файлу (кнопка не обязательна).

## 3. Windows: запись через Rufus / balenaEtcher

1. Выбери кардридер с SD-картой; сохрани все важные данные — **они будут уничтожены**.
2. Запусти Rufus или balenaEtcher и выбери скачанный полный образ `.img`.
3. Выбери **именно SD-карту** по её размеру и названию. Не системный SSD, NVMe или USB-диск с данными.
4. Начни запись raw-образа. **Не форматируй SD отдельно** и не создавай разделы до записи.
5. Дождись окончания операции и проверки (Etcher может проверить автоматически). Извлеки карту безопасно.
6. Если Windows предложит форматировать Linux-раздел ext4 — нажми **«Отмена»**. Форматирование разрушит прошивку.

Важный момент: внутри `.img` загрузчик T23N **уже расположен на LBA34**. Программа должна записать файл **с сектора 0/LBA0**, без дополнительного сдвига и без `seek=34`.

## 4. Ubuntu: запись через проверенный скрипт WIFICAM

Вставь SD в USB-кардридер Huananzhi. Сначала выполни команду, которая ничего не записывает:

```bash
lsblk -o NAME,PATH,SIZE,MODEL,TRAN,RM,MOUNTPOINTS
```

Убедись, что устройство — `TYPE=disk`, `RM=1`, `TRAN=usb` и оно **не содержит системный диск**. Проверь пути повторно при переподключении карты.

Скрипт из собранного исходного worktree: `build/jobs/<job-id>/wificam_T23N/scripts/write_thingino_wificam_sd.sh`. Его аргументы: **полный путь к целевому блочному устройству**, затем **полный путь к уже проверенному образу**.

```bash
# Пример синтаксиса; НЕ подставляй /dev/sdX до фактической проверки lsblk.
sudo sh /1tbdisk/PegineLab/build/jobs/ПОЛНЫЙ_ID_ЗАДАНИЯ/wificam_T23N/scripts/write_thingino_wificam_sd.sh \
  /dev/ПРОВЕРЕННАЯ_SD \
  /1tbdisk/PegineLab/build/jobs/ПОЛНЫЙ_ID_ЗАДАНИЯ/wificam_T23N/out/private-sd/thingino-t23-sd.bin
```

Если образ без Wi-Fi-конфигурации, он может находиться в `out/candidate-sd/` или `Thingino/`. Копируй **фактический путь** из раздела «Артефакты». Скрипт дополнительно проверяет USB/RM, MBR, MSPL, нужный размер, требует явное подтверждение `THINGINO-WIFICAM:/dev/sdX`, записывает с **LBA0** и сверяет SHA-256 чтением с SD. Использовать команду только после полного осознания, что данные на устройстве будут уничтожены.

## 5. Аппаратная проверка и откат

Вставь SD в камеру T23N, полностью выключив питание перед установкой. Проверь запуск, SSH, веб-порт `:8090`, CGI, RTSP, PTZ, Wi-Fi и восстановление после выключения. Если камера не загрузилась, сохрани логи и попробуй исходный проверенный по SD boot образ `0.1_test`. Новую прошивку нельзя объявлять рабочим релизом только потому, что кнопка проверки показала зелёный статус.
