# Скачать готовую прошивку T23N и записать на SD

Это инструкция для **полного дискового образа** профиля `t23n_sd`, полученного через YadroKreator. Для других плат и процессоров инструкции записи отличаются.

## 1. Дождаться успешного результата и проверить файл

После завершения сборки в разделе **Артефакты** сразу доступна кнопка **«Скачать образ .img»**. Нажатие **не компилирует ядро заново**: перед передачей файла сервер автоматически проверяет SHA-256, MBR, T23N MSPL **LBA34**, BOOT FAT16 `/uImage` **LBA2048** и ext4 ROOTFS **LBA34816**. Если файл повреждён, скачивание блокируется с ошибкой. Повторно компилировать рабочий образ не нужно. Кнопка **«Проверить образ перед записью SD»** в разделе Сборки остаётся для предварительной проверки и карты разделов, но не обязательна для начала скачивания.

При ошибке или отсутствии SHA нужно сначала исправить сборку. Зелёная проверка означает проверку **файла**, а не физической загрузки камеры.

## 2. Скачать прямо из браузера — одно нажатие

Открой вкладку **Артефакты**, найди успешную Git-сборку T23N и нажми **«Скачать образ .img»**. Больше ничего вводить не нужно: задача и путь определяются интерфейсом автоматически. Сервер проверяет уже созданный образ, затем отдаёт неизменённый файл `WIFICAM_T23N_<краткий-id>.img`. Никакой новой компиляции, форматирования или записи SD кнопка не запускает.

**Безопасность:** образ может содержать пароль Wi-Fi; у веб-панели пока нет пользовательской авторизации. Поэтому экспорт разрешён только с доверенной подсети `192.168.0.0/24` и с самого сервера (loopback). **Любой клиент внутри разрешённой подсети сможет скачать приватный образ.** Защитите LAN, изолируйте Wi-Fi для гостей и не открывайте порт `62404` в интернет.

Если подключаешься через отдельный защищённый VPN и адрес попадает в другую подсеть, администратор может явно задать `PEGINELAB_EXPORT_TRUSTED_NETWORKS` (список CIDR через запятую) для systemd user service и перезапустить панель. Указывать `0.0.0.0/0` нельзя. Не доверяйте заголовкам `X-Forwarded-For`. Передавать приватный образ через обычный HTTP в небезопасной сети нельзя; для удалённой работы используйте HTTPS/VPN или SCP/SFTP.

**GitHub используется для:** исходников, документации, offline-тестов SHA/MBR/LBA/FAT/ext4 и при желании публичного `SHA256`-манифеста без секретов. Саму приватную прошивку храним локально на Huananzhi. Проверяющий тест в GitHub Actions не даст случайно добавить `.img`, `.bin` или `.iso` в YadroKreator.

## 3. Windows: запись через Rufus / balenaEtcher

1. Выбери кардридер с SD-картой; сохрани все важные данные — **они будут уничтожены**.
2. Запусти Rufus или balenaEtcher и выбери скачанный полный образ `.img`.
3. Выбери **именно SD-карту** по её размеру и названию. Не системный SSD, NVMe или USB-диск с данными.
4. Начни запись raw-образа. **Не форматируй SD отдельно** и не создавай разделы до записи.
5. Дождись окончания операции и проверки (Etcher может проверить автоматически). Извлеки карту безопасно.
6. Если Windows предложит форматировать Linux-раздел ext4 — нажми **«Отмена»**. Форматирование разрушит прошивку.

Важный момент: внутри `.img` загрузчик T23N **уже расположен на LBA34**. Программа должна записать файл **с сектора 0/LBA0**, без дополнительного сдвига и без `seek=34`.

## 4. Ubuntu: запись через проверенный скрипт WIFICAM

Вставь SD в USB-кардридер Huananzhi. Сначала выполни команду, которая ничего не записывает:

```bash
lsblk -o NAME,PATH,SIZE,MODEL,TRAN,RM,MOUNTPOINTS
```

Убедись, что устройство — `TYPE=disk`, `RM=1`, `TRAN=usb` и оно **не содержит системный диск**. Проверь пути повторно при переподключении карты.

Скрипт из собранного исходного worktree: `build/projects/wificam_T23N/jobs/<job-id>/wificam_T23N/scripts/write_thingino_wificam_sd.sh`. Его аргументы: **полный путь к целевому блочному устройству**, затем **полный путь к уже проверенному образу**.

```bash
# Пример синтаксиса; НЕ подставляй /dev/sdX до фактической проверки lsblk.
sudo sh /1tbdisk/PegineLab/build/projects/wificam_T23N/jobs/ПОЛНЫЙ_ID_ЗАДАНИЯ/wificam_T23N/scripts/write_thingino_wificam_sd.sh \
  /dev/ПРОВЕРЕННАЯ_SD \
  /1tbdisk/PegineLab/build/projects/wificam_T23N/jobs/ПОЛНЫЙ_ID_ЗАДАНИЯ/wificam_T23N/out/private-sd/thingino-t23-sd.bin
```

Если образ без Wi-Fi-конфигурации, он находится только в `out/candidate-sd/`. `Thingino/` — старый проверенный эталон `0.1_test`, не результат задания и не экспортируемый кандидат. Копируй **фактический путь** из раздела «Артефакты». Скрипт дополнительно проверяет USB/RM, MBR, MSPL, нужный размер, требует явное подтверждение `THINGINO-WIFICAM:/dev/sdX`, записывает с **LBA0** и сверяет SHA-256 чтением с SD. Использовать команду только после полного осознания, что данные на устройстве будут уничтожены.

## 5. Аппаратная проверка и откат

Вставь SD в камеру T23N, полностью выключив питание перед установкой. Проверь запуск, SSH, веб-порт `:8090`, CGI, RTSP, PTZ, Wi-Fi и восстановление после выключения. Если камера не загрузилась, сохрани логи и попробуй исходный проверенный по SD boot образ `0.1_test`. Новую прошивку нельзя объявлять рабочим релизом только потому, что кнопка проверки показала зелёный статус.
