SD CARD EXPORT / T23N

Скачать и записать SD-образ

После успешной сборки нажми «Проверить SD», затем «Скачать образ». Для приватного образа с Wi-Fi потребуется одноразовый код из SSH-терминала сервера.

На Huananzhi: cd /1tbdisk/PegineLab/projects/YadroKreator, затем python3 download_access.py issue ИДЕНТИФИКАТОР_ЗАДАНИЯ. Полный ID отображается на карточке артефакта. Код действует 10 минут и используется один раз.

В Windows открываем скачанный .img в Rufus или balenaEtcher, выбираем именно SD через кардридер и запускаем запись. Предварительное форматирование не нужно. Файл является образом целого диска: MSPL уже расположен на LBA34, повторный seek=34 запрещён.

После записи — безопасное извлечение и проверка загрузки на T23N. Не форматируй предложенный Windows раздел ext4.

Подробная инструкция: скачать, записать, проверить и восстановить

⌁ Файлы с персональными настройками Wi-Fi нельзя раздавать по открытому HTTP без дополнительной авторизации. Кнопка загрузки использует одноразовый код, полученный через SSH.
