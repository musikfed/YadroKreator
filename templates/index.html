ЛИНИЯ 02 / IRILA BAIKAL · ACER x86-64

Irila Baikal — независимый проект

Отдельный GitHub SHA, рабочая папка, systemd unit и журнал. Никаких драйверов T23N и SD-образов.

◈ Дерево Irila—Только x86-64 · Secure Boot · отдельный CI

Исходники и проверка конвейера

Проверяется только закреплённая ветка musikfed/Irila_baikal_v1.0/main. Кнопка ниже выполняет аудит исходников и создаёт отчёт — не компилирует ядро и не создаёт IMG.

Полная сборка Irila: Canonical/Microsoft Secure Boot, GPT/EFI/ext4 и привилегированные loop/mkfs. До отдельной настройки безопасного root-окружения запускается в своём GitHub Actions workflow. Она не является сборкой кастомного ядра T23N.

Путь: /1tbdisk/PegineLab/projects/wifcam_helper. Инструменты диагностики запускаются отдельно на CORE и не передают произвольные команды ядру. Для T23N передаётся только утверждённый JSON с WIFICAM_WEBRTC=0|1.

SD CARD EXPORT / T23N

Скачать и записать SD-образ

После завершения сборки нажми «Скачать образ .img» на карточке нужного файла. Никакого одноразового кода, ID или терминала: панель сама выберет образ и сверит SHA256, MBR, MSPL LBA34, FAT16/uImage и ext4 перед передачей. Сборка ядра не повторяется. Кнопка «Проверить SD» остаётся для просмотра схемы.

Доступ: скачивание приватных образов разрешено только клиентам доверенной локальной сети Huananzhi (по умолчанию 192.168.0.0/24 и loopback). Панель всё ещё без входа: любой, кто попал в разрешённую сеть, может скачать образ с персональными Wi-Fi настройками. Не открывай порт 62404 в интернет; для удалённого доступа используй защищённый VPN или SSH.

В Windows открываем скачанный .img в Rufus или balenaEtcher, выбираем именно SD через кардридер и запускаем запись. Предварительное форматирование не нужно. Файл является образом целого диска: MSPL уже расположен на LBA34, повторный seek=34 запрещён.

После записи — безопасное извлечение и проверка загрузки на T23N. Не форматируй предложенный Windows раздел ext4.

Подробная инструкция: скачать, записать, проверить и восстановить

⌁ Экспорт доступен одним нажатием из разрешённой LAN. Это не персональная авторизация: защити сеть и не публикуй приватные Wi-Fi-образы в GitHub. Скачивание не прошивает карту и не запускает сборку.
